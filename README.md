Own — fuck off bear 


This is the main repository for the VyOwn programming language project , a dialect of Own. 


Why VyOwn? 
VyOwn is designed for writing low level software , such as: 

operating systems 

drivers 

firmware 


The VyOwn programming language is easy to learn once you have mastered classic Own. 


Writing and reading VyOwn code is extremely easy, furthermore, VyOwn code is significantly more concise than classic Own—in terms of lines of code, it is comparable to C and often even more compact.
